# Smart College Planner

A Java-based web application designed to help students manage their academic tasks efficiently.

## Features
- Add tasks with priority levels
- Set deadlines for tasks
- Organize and track academic work

## Tech Stack
- Java
- HTML, CSS, JavaScript

## About
This project was developed to improve task organization and apply logical problem-solving concepts in a real-world scenario.

## Status
Work in progress – continuously improving and adding features.
